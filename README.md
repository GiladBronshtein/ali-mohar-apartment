# הדירה בעלי מוהר: הדמיה תלת-ממדית

**האתר:** https://giladbronshtein.github.io/ali-mohar-apartment/

הדמיה תלת-ממדית של הדירה בעלי מוהר 6, רעננה (קומה 2). המודל נבנה לפי תוכנית המכר, תוכניות החשמל, האינסטלציה והמיזוג של הקבלן, ותמונות מהשטח. הוא רץ כולו בדפדפן ואין לו שרת או בק-אנד. זה אתר סטטי שמוגש מ-GitHub Pages.

## מה יש באתר

- הליכה חופשית בכל הדירה: גרירה מסובבת את המבט, חצים או גלגלת זזים, בטלפון צביטה ושתי אצבעות.
- 33 זוויות מוכנות בלוח הבקרה: סלון ומטבח, חדרים, זוויות נוספות ומבט ציפור.
- מצב יום וערב, מידות, תקרה, דלתות סגורות ווילונות.
- 17 תמונות שרונדרו ב-Blender Cycles, בכפתור "תמונות באיכות מלאה" (רונדרו מחדש מהמודל העדכני ב-7.10.2026).

## מבנה הריפו

| `lm/` | מפות תאורה מחושבות מראש: הצללה עדינה בפינות כברירת מחדל, התאורה המלאה עם `?baked=1`. נבנה עם `source/lm/` |

## איך מעדכנים את האתר

כל השינויים נעשים ב-`source/salon.html`. אחר כך:

```bash
cd source
python3 build_site.py        # בונה מחדש את ../index.html, ../site.webmanifest ו-../404.html
cd ..
git add -A && git commit -m "..." && git push
```

GitHub Pages מתעדכן תוך כדקה אחרי ה-push.

הרצה מקומית (צריך שרת, כי מודולים של JavaScript לא נטענים מ-`file://`):

```bash
python3 -m http.server 8000
# ואז: http://localhost:8000/
```

## רינדור מחדש של התמונות (Blender Cycles)

הסקריפטים ב-`source/` מניחים שמריצים אותם מתוך `source/`, עם Python ו-Blender כמודול (`pip install bpy`, נבדק על 5.2) ו-Node.

```bash
cd source
npm install                                # three + playwright
npx playwright install chromium            # אם אין כרום מקומי (או CHROME_PATH לכרום קיים)
ln -s ../assets assets                     # פעם אחת: כדי שהייצוא יראה את הטקסטורות מצילום
python3 -m http.server 8765 &              # exportglb.mjs טוען את ההדמיה מהשרת הזה
node exportglb.mjs                         # מייצא את המודל ל-apartment.glb ואת הזוויות ל-views.json
GPU=1 python3 cycles_render.py kitchen day 128 1440 900 out/kitchen.png 2.7   # זווית, day/eve/lit, דגימות, רוחב, גובה, קובץ, חשיפה
bash render_gallery.sh                     # 17 התמונות של הגלריה ישר ל-../renders/, עם המשך מאיפה שנעצר (logs/gallery_progress.txt)
git checkout -- apartment.glb              # לא מעלים את המודל המיוצא (כ-110 MB)
```

עם `GPU=1` (Metal) תמונה לוקחת כ-2 דקות ב-128 דגימות; בלי כרטיס מסך, כ-8 דקות על 2 ליבות ב-48 דגימות. זווית חדשה בגלריה צריכה גם שורה ב-`render_gallery.sh`, ב-`renders/status.json` וברשימת `RENDERS` ב-`salon.html`.

## בדיקות

- `roomdims.py`: מודד את המידה הפנימית של כל חדר מהקירות במודל ומשווה למידות בתוכנית המכר. היום כל החדרים מתאימים בסטייה של עד חצי ס״מ.
- `clearance_audit.py`: בודק מעברים, פתיחת דלתות ומגירות מול רהיטים.
- `sitetest.mjs`: טוען את האתר בכרום בגודל מחשב ובגודל טלפון, ובודק שגיאות, אייקונים ושכל 17 התמונות נטענות.
- `audit/report.md`: השוואה של כל מספר שכתוב בתוכניות מול המודל.

## מגבלות ידועות

- **גבהים:** גובה התקרה 2.70 מ׳ הוא המינימום שכתוב במפרט המכר ("לא פחות מ-2.70"), כך שבפועל הוא יכול להיות מעט גבוה יותר. גובה לוח החשמל לא כתוב, ולכן הוא הערכה. אדני החלונות וראשי הפתחים לקוחים מתוכנית הביצוע (בדיקה שלישית).
- **סביבה:** המגרש, הבניין (כולל קומה 1 ודירת הגן שמתחתינו), הגינות, הגדר, החניה והחזית הקרובה של הרחובות לפי תוכניות קומת הקרקע והקומה הטיפוסית (בדיקה חמישית). הצד הרחוק של הרחוב, בית הספר, המגדל והבניינים מסביב לפי התמונות מהמרפסת, בסטייה של כמה מטרים. גובה הגדרות, כיוון המדרגות בכניסה וגובה הרחוב לא כתובים. לבניינים מסביב יש חזית כללית (חלונות, תריסים, מזגנים), לא החזית האמיתית שלהם. צבע האדמה במגרש נשאר ניטרלי עד שתאשרו את הצבע הכתום שבתמונות.
- **פריטים במטבח:** הפירות, בקבוק היין וקרש החיתוך (Poly Haven) נטענים רק במחשב. בטלפון רואים פירות פשוטים.
- **מראות:** המראות משקפות את החדר רק במחשב (איכות גבוהה). בטלפון הן משקפות סביבה כללית.
- **תמונות Cycles:** כל 17 התמונות רונדרו מחדש מהמודל העדכני (7.10.2026). שינוי נראה לעין אחרי התאריך הזה לא יופיע בהן עד הרינדור הבא. גרסת ה-artifact של claude.ai קפואה, ואין בה `assets/`.
- **תאורה:** בהדמיה החיה התאורה מקורבת. מהחישוב המוקדם ב-Cycles (`source/lm/`) נלקחת כברירת מחדל רק ההצללה בפינות, מתחת לרהיטים ולאורך התקרה. התאורה המחושבת המלאה עדיין כהה יותר מהחיה, ולכן היא כבויה; מפעילים אותה עם `?baked=1`. ההשתקפויות במשטחים מבריקים (שיש, נירוסטה, כרום, כלים סניטריים) לקוחות מתמונות 360 שרונדרו בסלון ובשני חדרי הרחצה.
- **מיקומים מהתוכניות הטכניות:** בדיקה חוזרת מול הצילומים ברזולוציה מלאה (`audit/recheck/`) תיקנה דלתות, קירות, אינסטלציה, מיזוג וחשמל. מיקום שלא כתוב עליו מספר נמדד בקנה מידה מהצילום, בדיוק של כמה ס״מ. כמה פרטים נשארו פתוחים כי הגיליונות סותרים זה את זה (עמוד 2, לוח החשמל, המעבה, הדוד), ראו `PROJECT_MEMORY.md`.
- **רהיטים ומנורות מהתמונות:** הספה, שולחן הסלון, השטיח, פינת הישיבה במרפסת, הריחופית והמנורות נבנו לפי תמונות של מה שיש לכם היום. המידות משוערות מהתמונות.
- **בדיקה שנייה מול התוכניות** (`audit/recheck2/APPLIED.md`): הנמכת הגבס במסדרון היא 35 ס״מ ולא 25 (הספרות בתוכנית המיזוג כתובות בכתב ראי). פריטים שנשארו פתוחים, כמו רוחב המעבר מהמסדרון לסלון ומיקום המזגן בחדר ההורים, רשומים שם.
- **קרמיקה מהמפרט** (`CERAMICS.md`): האריחים מצוירים לפי התמונות בקטלוג, ולכן הם קירוב. במצב תאורה מחושבת (`?baked=1`) ההחלפה לא מתעדכנת.
- **בדיקה שלישית מול התוכניות** (`audit/recheck3/APPLIED.md`): חלונות, אדנים וראשי פתחים מתוכנית הביצוע, מעבר 120 מהמסדרון לסלון, ארגז הצנרת, המזגן בחדר ההורים, המקלחת ופריטי חשמל.
- **בדיקה רביעית** (`audit/recheck4/`): תוקנו פינת החיפוי במטבח, הנישה במקלחון ההורים, החיפוי בנישת הכביסה ובחלון חדר הרחצה ומסגרות החלונות.
- **בדיקה חמישית** (`audit/recheck5/APPLIED.md`): תקרה 2.70, פורצלן בממ״ד, כיורים משולבים במשטח, מזגן שני, שקעים במרפסת ובאי, אריחי 80×80 מבריקים, והסביבה לפי תוכניות המגרש. הסתירות בין המסמכים (שטח, מידות דלתות וחלונות, מידות אריחים וארונות) רשומות שם.

## רישיונות

three.js, three-mesh-bvh ו-three-gpu-pathtracer הם ברישיון MIT, וקבצי הרישיון נמצאים ב-`vendor/`. הקבצים ב-`assets/` הם מ-Poly Haven (https://polyhaven.com) ומ-ambientCG (https://ambientcg.com, הטקסטורות `Metal009`, `Leather026` ו-`Marble021`), כולם ברישיון CC0. התוכניות והתמונות שייכות לבעלי הדירה ולקבלן.
